# 🎨 Interactive Avatar (p5.js)

An interactive digital self-portrait created as part of the **Girls Who Code (GWC)** "Welcome to p5.js" course project.

### 🌟 About the Project
This project uses creative coding to draw a customized avatar alongside an inspirational quote. Users can interact directly with the canvas to trigger changes in expressions and visual elements.

### 💡 Features
- **Custom Visual Design:** Built using p5.js shapes, color fills, arcs, and typography.
- **Interactive Controls:** Click anywhere on the canvas to toggle expression changes (closing/opening eyes and changing expressions).
- **Dynamic Canvas:** Responsive layout using p5.js event functions.

### 🛠️ Built With
- **JavaScript (ES6)**
- **[p5.js](https://p5js.org/)** — Creative coding library for HTML5 Canvas
